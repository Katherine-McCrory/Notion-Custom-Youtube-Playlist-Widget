Notion Embed Guide

1. Uploading HTML files endlessly loads? Notion's code upload block can only store raw files. It cannot execute JavaScript web apps directly.

2. Solution: Deploy this single HTML file to Vercel, GitHub Pages, or Netlify, then copy your live web link.

3. Embedding in Notion: In your Notion page, type /embed, paste your Vercel URL, and click Embed Link.
